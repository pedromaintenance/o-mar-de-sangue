O MAR DE SANGUE — PWA PRONTO

Como testar localmente:
1. extraia o ZIP;
2. abra a pasta num servidor web simples (por exemplo, Python ou VS Code Live Server);
3. acesse index.html pelo navegador.

Como publicar no GitHub Pages:
1. envie todos os arquivos da pasta para o repositório;
2. ative o GitHub Pages na branch principal;
3. abra a URL publicada;
4. no celular Chrome/Edge, use “Instalar app” ou o botão interno.

Observação:
- o jogo foi preparado para funcionar offline após a primeira abertura, via service worker.
